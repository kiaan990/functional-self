functional-self · research project · Kiaan Hiranandani · Oct 2026

An AI agent that learns about itself, and has to prove it.

Most chatbots improvise a personality every time you talk to them and forget it afterwards. This project builds an agent that keeps a record of what it actually did, forms beliefs about its own habits from that record, and is only allowed to hold a belief it can back with real evidence.

Can an AI develop a stable, honest model of itself from its own experience?

The idea in three sentences

The program owns the self, not the AI model

The language model does the thinking in the moment. Everything that lasts (identity, mood, memory, beliefs) lives in ordinary code and a database the model can only ask to change.

The model proposes, the code decides

Every change the model suggests is checked, capped and logged by code. A mood can only move a little at a time and drifts back to normal. A belief can only grow with new evidence.

A thought is not a fact

If the agent thinks "I rush when I'm unsure", that is a hypothesis. It only becomes a belief after the agent finds real past episodes that support it, and it also has to look for episodes that contradict it.

The experiment

Take one agent, clone it into two identical copies, and give them different lives. Agent A lives in a world where answering a vague request without checking usually goes badly, and checking first usually goes well. Agent B lives in the mirror image. After 200 experiences each, both are tested on the same 20 unseen situations with their mood pinned to neutral, so only what they have learned about themselves can make a difference.

Agent A
100%

checks first on vague requests. Holds the belief "When uncertainty is high, I commit before checking assumptions" with 3 supporting episodes.

Agent B
12%

checks first on vague requests. Came up with the same hypothesis, found 0 episodes for and 5 against, and rejected it.

Then each part of Agent A's mind was switched off, one at a time, and its life replayed.

Turn off the self-model, reflection, or background thinking and Agent A becomes Agent B. Turn off mood or memory recall and nothing changes. The individuality lives in the evidence-to-belief pipeline, not in the agent's mood.

What it claims, and what it doesn't

it shows
  • An agent can form beliefs about its own habits from recorded experience.
  • Those beliefs trace back to real episodes, 100% of the time.
  • They change later decisions even when mood is neutral.
  • Repeating a thought cannot inflate a belief.
  • Two identical agents with different lives become measurably different.
it does not show
  • Consciousness, feelings or anything subjective. The "mood" variables are numbers that gate decisions.
  • How a real language model judges evidence. This first version used a deterministic stand-in brain, so it validates the control system. The same harness runs against Claude next.
  • Results across many random seeds. One run per arm so far.

Where the code lives

About 1,500 lines of Python, 14 tests (one per success criterion), no framework.

config/SOUL.mdThe agent's constitution. Read-only to the model; its fingerprint is checked at every start. affect.pyThe six mood variables, their limits, caps and decay. self_model.pyBeliefs with confidence, evidence lists, version history, rollback, and the "no circular evidence" check. reflection.pyHypothesis → search real history → evidence for and against → bounded update. consolidation.pyThe nightly "sleep": find patterns, look for counterexamples, tidy old memories. scheduler.pyCheap background ticks with a daily budget. Most ticks do nothing. agent.pyThe loop that ties it all together. evaluation/The two lives, the 20 test situations, the metrics, the clone experiment and the charts. cli.pyTalk to an agent and inspect it: /self-state /why-self /reflect /rollback.
